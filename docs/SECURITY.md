# Security Documentation

## Threat Model
Aegis addresses:
- Prompt Injection
- Jailbreaks
- Secret Extraction
- Contextual Poisoning
- Tool Abuse
- Role Manipulation

## Attack Taxonomy
1. Instruction Override
2. Role Change
3. Secret Extraction
4. Tool Abuse
5. Credential Theft
6. Context Poisoning
7. Multi-step Jailbreak
8. Encoded Instruction
9. Indirect Injection

## Defense Strategy
Defense in Depth utilizing multiple tiers of detection to catch varied complexities of attacks.
